# 📌 杉板桥社区CloudRise科普工作台｜RAG科普AI助手
> Project Type：AI Application / RAG Knowledge Base Product
> Internship Project｜AIPM Portfolio Core Work
> Background：Shabanqiao Community Industrial Heritage Popular‑Science Project
> Status：Iterative Operation & Online Pilot

## 1. 项目痛点（Pain Points）
### 业务痛点
1.社区科普人力有限，线下研学、科普宣传依赖工作人员人工整理资料，内容生产慢、更新周期长；
2.东郊记忆工业遗存史料零散，纸质档案、碎片化推文难以统一检索，居民咨询无法快速精准答复；
3.科普活动策划耗时久，缺少标准化素材库，每次研学活动需要重复搜集文案、海报素材；
### AI层面痛点
1.直接调用通用大模型容易产生**历史资料幻觉**，编造工业历史、人物、时间线，社区科普对史实真实性要求极高；
2.通用大模型无法绑定本地专属知识库，回答脱离杉板桥本地场景；
3.缺少人工复核流程，AI输出内容不能直接对外发布，缺乏产品侧质控闭环。

## 2. 用户调研 & 用户分层
### 目标用户
1️⃣社区工作人员（核心B端用户）
-需求：快速检索史料、自动生成研学方案、科普文案、活动海报提示词，减少文案重复劳动；
2️⃣社区居民（C端普通用户）
-需求：查询东郊记忆工业历史、场馆介绍、研学报名信息，获取通俗易懂的科普内容；
3️⃣研学团队/来访游客
-需求：获取路线讲解、工业遗存背景故事，需要结构化、故事化科普文稿。

### 用户调研结论
1.用户不追求复杂AI对话，**优先保证史料准确，其次提升内容生产效率**；
2.居民排斥过于专业晦涩文本，AI输出必须通俗化；
3.工作人员强烈要求增加**人工审核AI生成内容**的功能，杜绝错误科普信息对外传播。

## 4. 核心 PRD｜主要功能模块

### Module1｜知识库管理（后台，工作人员使用）

1. 文档上传：PDF、Markdown、图文资料批量导入；
2. 知识库分类：工业遗存史料、社区活动档案、研学课程库；
3. 手动新增 / 删除条目，支持定期更新资料；
4. 向量库一键重新切片更新。

### Module2｜智能问答（面向居民 & 游客）

1. 基于本地知识库回答东郊记忆、杉板桥社区相关科普问题；
2. 禁止回答知识库以外无关问题，限定问答边界；
3. 引用资料来源片段，展示参考出处，增强可信度。

### Module3｜AI 科普内容生成（B 端生产力功能，核心价值点）

根据知识库素材一键产出：
✅研学活动策划方案
✅科普公众号短文
✅AIGC 海报生成提示词（对接多模态 IP 绘图）
✅社区科普宣讲稿

> 
> 产出文案支持导出、保存、提交人工审核。

### Module4｜AI 内容审核与质控流水线

1. 幻觉风险标记：检测回答与知识库原文冲突之处；
2. 人工编辑修改 AI 结果；
3. 优质定稿内容回流补充知识库，形成持续迭代闭环。

## 5. AI 幻觉风险产品化设计（AIPM 重点亮点）

> 
> 不依赖算法优化，从**产品机制层面降低幻觉**
> 1. 边界约束提示词：强制模型仅依托检索到的知识库内容作答，无相关资料直接回复 “暂无相关档案资料”，禁止编造信息；
> 2. 溯源引用：AI 回答末尾附带检索原文片段，工作人员可快速核对真伪；
> 3. 风险标记策略：当检索匹配度低于阈值时，自动弹窗提醒「信息不足，建议人工复核」；
> 4. 内容发布权限隔离：AI 生成文案**不能直接对外推送**，必须经过人工确认后才可使用；
> 5. 知识库版本管理：每次资料更新留存历史版本，方便溯源错误来源。

## 6. 落地复盘｜效果、缺陷、后续迭代方向

### ✅落地收获

1. 社区工作人员科普文案撰写耗时下降约 40%，研学策划效率明显提升；
2. 本地史料问答准确率高于通用大模型，基本杜绝无依据编造史实；
3. 打通 RAG 文本生成→多模态 IP 海报制作链路，形成社区科普 AI 工作流，实现 CloudRise 工作台 0‑1 落地；

### ⚠现存缺陷（面试高频加分，敢于暴露产品短板）

1. 长文档切片策略固定，长段落史料容易上下文割裂，出现片段断章取义；
2. 向量检索只依靠相似度，缺少业务语义权重，部分专业史料召回不准确；
3. 缺少用户反馈采集入口，无法自动收集居民对 AI 回答的评价用于迭代；

### 🚀后续产品迭代规划

1. 增加分层切片策略，区分叙事类文本 / 档案数据；
2. 增加用户点赞 / 纠错反馈入口，反馈数据驱动知识库迭代；
3. 接入多模态能力，实现史料图文联动检索，AI 直接生成科普配图；
4. 增加研学路线智能编排、活动报名联动，打通线上 AI 咨询与线下社区活动闭环。
